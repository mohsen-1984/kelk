Fontprints from font files

Kelk reads a PDF's glyph by its outline when the file's own names are missing or wrong. For that it keeps, per font, the hash of each glyph's outline and its character — in lib/pdfimport/fontprints.js. This page adds fonts to that file.

  1. Drop the fonts' .ttf files below (regular, bold … each is a face of its own).
  2. Check the table, then press Download fontprints.js.
  3. Put the downloaded file in lib/pdfimport/ of the repository, in place of the old one (on GitHub: a new branch, Add file → Upload files, then a pull request).

Nothing is uploaded: the fonts are read in this page only. The file holds hashes and characters, no font.
