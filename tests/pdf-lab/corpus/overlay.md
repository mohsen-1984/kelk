# Web page layers

This page is drawn the way web applications print: inside a framed card, with a second text layer laid exactly over the first, and with one paragraph covered by an opaque panel drawn after it.

## What the reader sees

Only the text that shows on the page comes back, each word once.

The panel above hides a paragraph, and that paragraph is not part of what the page says.
