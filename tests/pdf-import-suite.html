Kelk — PDF import tests

PDF → Markdown only (PdfImporter); the other importers — .docx, .html, pasted rich text — are MarkdownImporter's, tested by builder-suite.html and math-file.html. Select PDF files (for instance from tests/pdf-lab/pdf/). Files whose name ends with --<doc>.pdf are scored against that corpus document (tests/pdf-lab/corpus/<doc>.md, read from pdf-lab/corpus.js — offline, from file://), with the floors of pdf-import-corpus.js. The table shows recall (words found), order (longest common run), and structure scores (headings, lists, tables, code, quotes). Green meets the floor; red does not. The full lab, with its own scorer and gate, is tests/pdf-lab/ (Node).
