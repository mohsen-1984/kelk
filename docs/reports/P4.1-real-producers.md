## 1. What changed

Until now Word, Excel, PowerPoint and Microsoft Print to PDF were only imitated in the lab, glyph by glyph. P4.1 adds
their real output, made on this Windows machine.

| Part | What it is |
|---|---|
| `tests/pdf-lab/corpus/real-src/` | 8 own CC0 documents: a Persian memo, a mixed Persian / English report with tables, an Arabic letter, an English readme, two Persian sheets (with and without borders), a Persian and an English deck; hand-written references `corpus/real-*.md` |
| `scripts/make-real.ps1` | Word, Excel and PowerPoint 2024 through COM: Save as PDF and Microsoft Print to PDF; restores the default printer and Office's numeral settings; sets Excel's separators for every sheet; ends with `strip-meta.js` |
| `scripts/make-real.js` | the HTML versions through Edge 156, Playwright's Chromium 156 and Firefox 152 |
| `pdf/real-producers/` | **44 PDFs** (the 8 documents plus the lab's `word-*` and `xl-border-*` office files through the same Office paths) |
| `scripts/strip-meta.js` | clears author, last editor, manager, company and local folder paths from the Office sources and the PDFs (Info and XMP), keeps Producer / Creator; refuses to write a PDF whose decoded page content would change |
| `profile.js`, `features.js` | producer table += Word / Excel / PowerPoint 2024, Print to PDF, Edge; application × direction table — no empty cell for {Word, Excel, PowerPoint} × {rtl, ltr} |
| Generators | `build-corpus-js.js`, `tools/build-samples.js` normalise line ends on read (independent of `core.autocrlf`) |

What remaking needs (Office **LTSC 2024** for its Aptos defaults, Print to PDF, Edge, Firefox, Node, Traditional
Arabic, **B Nazanin** installed per user) is in `corpus/real-src/README.md` and `docs/ContributeLog.md` →
Prerequisites. LibreOffice is not installed here, so the plan's `lowriter--` real files are not made (CI could add
them).
