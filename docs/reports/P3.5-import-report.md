## 1. What changed

The PDF import's up-to-four transient note toasts (`scripts/importer.js`) are replaced by one dismissible panel,
`#import-report` (`scripts/report.js`), fed by the importer's structured `r.report` (the P3.4 contract).

| Part | What it does |
|---|---|
| `Kelk.importReport.fromResult(r)` | pure: `r.report` normalised (lists always present, a flag never repeated as a note), or built from the older fields (`r.pages`, `r.quality.flags`, `r.notes`, `r.failedPages`) for results without one |
| Summary line | pages per mode (full / simplified / text only / OCR / not read) and the mean confidence |
| Findings | each quality flag and note in words, with the pages it concerns (`K.ui.pageList`, at most 12 then "…") |
| Pages table | every page not read in full: its mode, confidence and why (`lowConf`, `lostGlyphs`, `extractFailed` …); a page that could not be read at all shows as "not read" |
| "Re-import in safe mode" | re-runs the import with `mode: 'safe'` from the kept bytes, its explanation shown under it; absent for a report already in safe mode and for multi-file imports |
| "Copy report" | the report as plain text (no bidi isolates) |
| When it shows | only when there is something to tell: a page not in full, a flag, or a note that is not *quiet* (`kelkSource`, `kelkMath`, `monoBody` alone do not open it) |
| Accessibility | `role="region"` with a name, focus moves in and back (×, Escape, or a clean import that closes it), no live region of its own (the focus move announces it once) |
| Words | 31+ strings in fa / en / ar; every `_note('code'` the importer emits has a key — `tests/unit/report.test.js` derives the list by grepping `lib/` |

Screenshots (fa / en, light / dark, phone, a typical file, a table) in `docs/reports/P3.5/` (for example [fa-light.png](P3.5/fa-light.png)), made by
`docs/reports/P3.5/screenshots.js` from `tools/report-sample.js`.

## 3. Review

The reviewer drove the app over `file://` with real PDF imports (clean files, files with notes, the ladder lab files,
several files, a zip), safe re-import and undo, Copy, focus and Escape, language and theme switches, axe on a real
report, and the heap after closing the panel.

| Finding | Verdict | Action |
|---|---|---|
| `kelkMath`, `monoBody`, `watermarkDropped` had no words (shown as raw codes) | confirmed | strings added; the test now takes the codes from the importer instead of a hand list |
| informational codes alone opened the panel after a clean import | confirmed | *quiet* notes: listed, but never a reason to open it |
| the PDF bytes were kept after the panel closed (three retainers: the task promise, the dialog handlers, the result) | confirmed with a heap snapshot | bytes kept only for a single-PDF import, released on close and on the next import (`Kelk.ui.report.release()`); heap checked |
| a page not read at all looked like a simplified one | confirmed | shown as "not read" (`failed`); the importer's side (`failed: true` in `r.pages`) is the P3.4 fix M5 |
| focus lost when the panel closed itself | confirmed | focus returned |
| at desktop sizes the findings and rows were cut | confirmed | panel sized to its content with scroll shadows |
| plural of "1 page", list separator, safe-mode hint not visible | confirmed | fixed; screenshots redone |
