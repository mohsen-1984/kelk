## 3. Decisions

1. **ESLint not repeated in `site.yml`:** `tooling.yml` runs `npm run lint` on the same triggers; a copy would show
   one error as two red checks. Recorded in `site.yml`'s header.
2. **Links offline on push / PR**, external URLs weekly and on demand: other servers' rate limits and bot blocks
   should not fail a change that cannot fix them.
3. **lychee from the release binary with a SHA-256 check**, not the action: the same binary runs locally.
4. **Size budget at the measurement rounded up to the next 5 kB** (1,985,000), above the plan's "≤ 1.93 MB": the
   plan's figure was the size when it was written; the budget's job until P5.1 is to stop growth. The two parts
   measured 1,970,171 bytes on their own base; the stack (with P1.3's and P1.4's review fixes) measures 1,982,706.
5. **axe injected with `page.evaluate`**, so the page is checked under its real CSP (`bypassCSP` would test a page
   no user gets).
6. **Only serious and critical fail**; moderate / minor are printed. Allow-list selectors are matched in the page.
7. **Accessibility fixes in the preview only**, so exports do not change; the BidiView fix is the exception (the
   bug was in the library, and it also removes an empty link from the HTML export).
8. **The scheduled run checks links only**; the other jobs give the same answer for the same commit.
