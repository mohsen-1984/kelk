## 2. The stress finding

`run-stress.js` failed on CI after the Playwright upgrade — for `main`'s importer as well: "the main thread held
19,240 ms at once". A CPU profile put 26.9 s of self time in one callback of `_formsByWidth` (`extract.js`):
it listed `Object.keys(byFont)` once per candidate font for every font — 841 × 1,095 fonts on the 276-page stress
file, cubic in the number of fonts. The block was always there: under Chromium 141 it held the thread **52 s**,
but that browser's long-task observer never reported it, so the check passed. Fixes: the ids are listed once
(same font chosen); `_gsubBogus` groups the glyphs by font once instead of a pass over every page per font
(another 1.2 s block); `run-stress.js` adds a heartbeat (the longest gap between 50 ms ticks) so the check no
longer depends on the browser's observer. The big file: 48 → 18 s, longest task 453 ms, heartbeat gap 494 ms;
the Markdown byte-identical.
