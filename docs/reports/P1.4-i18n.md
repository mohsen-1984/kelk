## 3. Behaviour notes

- **The plan's «جدول» row.** The Arabic interface did not get the Persian «جدول»: `lang === 'fa' ? 'جدول' : 'Table'`
  gave it the English "Table". The Arabic word is also «جدول», so the fix is the same; the test checks both "is
  «جدول»" and "is not Table".
- **Dates.** Only a *custom* header/footer has `{date}`. RTL: Arabic interface → `ar-u-nu-latn` (Gregorian, Arabic
  month names, Latin digits as before), Persian and English interfaces → `fa-IR-u-nu-latn` (Solar Hijri) — the same
  language choice as the page/of/contents words. LTR headers stay `en-GB`. The direction is `Kelk.names.hfDir()`
  (setting, else the preview's direction), as for the page/of words.
- **The 9 unused keys, all removed:** `language` (the old two-language toggle's label; the names now come from
  `K.i18n.languages`), `pageLabel` / `fromLabel` (the page/of words follow the header direction, from
  `K.config.rtlWords` and `exporter.labels`), `loadingFonts` / `pdfReading` (replaced by the task dialog's
  `taskExport` / `taskImport` / `taskPage`), `titleNone`, `titleAuto`, `closeEditor` (the editor has no close button
  since 2.0), `sample`. None was read anywhere (`lib/`, `tests/`, `tools/` checked).
- **Hard-coded strings moved (9):** the nested-table word (×2), the size unit, the language group's `aria-label`,
  "X did not load", "cannot load X", the page-list separator (×2 tests on the language), the logo's `alt`.
  **Kept on purpose:** `'unknown library '` / `'unknown output '` (programming errors, never reached by a user);
  the LTR document words "Page", "of", "Contents" in `exporter.js` (they are the document's language for an LTR
  header, not the interface's); language names in `K.i18n.languages`; `toLocaleString('en-US')` in the stats (Latin
  digits, deliberate); index.html's static "Language", "0 KB" (replaced at start, P1.4 does not own those lines).
- **First visit.** `firstLanguage()` now lives in `boot.js` and `main.js` calls it; the result is unchanged (Persian
  for fa / prs or an Iranian / Afghan time zone, Arabic for ar, else English).
- **Not in `boot.js`:** the layout (side / stack) is a class on `#workspace` in `<body>`; `main.js` still sets it, so
  a stored "stack" layout can show "side" for the moment the scripts load (not a language/theme flash; noted).
- **Load order for P1.2.** `boot.js` is a classic, synchronous script before the stylesheets; P1.2's CSP `<meta>`
  must come before it in `<head>` to apply to it (a CSP meta governs only what follows it).

## 6. Open issues

- index.html's `#st-size` keeps `dir="ltr"` and the static "Language" / "0 KB": `editor.js` and `main.js` override
  them at start; a later change owning those lines could drop them.
- The `.docx` box shows "docx." in RTL interfaces — deliberate per `names.js:154` (the dot next to the name in
  reading order); not changed.
- `check-i18n` reads `.t(…)` calls by pattern, not a parser: a key built in another way (`const k = …; t(k)`) would
  be reported unused — the report then names it, so it cannot pass silently.
- Layout (side / stack) is still applied after the scripts load (§3).
